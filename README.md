# Google Play Store App Analysis

## Project Overview

This project analyzes Google Play Store application data to identify factors that may influence app success and user engagement.

The analysis explores app attributes such as ratings, reviews, downloads, category, price, developer, last updated date, version, and app size using Python and Pandas.

## Dataset

The dataset contains information about Google Play Store applications, including:

- App Name
- Rating
- Reviews
- Downloads
- Price
- Category
- Developer
- Last Updated
- Version
- Size

The notebook contains analysis performed on 491 app records across 10 attributes.

## Objectives

- Analyze the characteristics of applications on the Google Play Store.
- Explore relationships between ratings, reviews, downloads, pricing, and other app attributes.
- Identify patterns that can help understand factors associated with app success.
- Perform exploratory data analysis using Python and Pandas.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas

## Project File

`APP-TREND-ANALYSIS.ipynb`

The Jupyter Notebook contains the complete analysis and outputs.

## How to Use

1. Download or clone this repository.
2. Open `APP-TREND-ANALYSIS.ipynb` using Jupyter Notebook or JupyterLab.
3. Review the analysis and visualizations included in the notebook.
